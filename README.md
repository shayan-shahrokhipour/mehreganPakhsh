# Mehregan Pakhsh

A React-based automotive parts marketplace.

## About Project

Mehregan Pakhsh is an online store for automotive spare parts.
The project focuses on Iran Khodro and Saipa spare parts.

## Features

- Responsive design
- Product listing
- Product details page
- Related products
- Search functionality
- Shopping cart
- Product filtering
- Error handling
- Loading state
- 404 page

## Technologies

- React
- React Router
- Context API
- useReducer
- Axios
- CSS Modules
- React Icons
